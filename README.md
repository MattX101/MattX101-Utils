# MattX101 Utils

A Utility library used by my other projects.

The reason this is its own project is due to the desire to have single project where all the work is handled instead of the same functions deployed across multiple projects with their own modifications.

# Technologies Used

- Unity
- C#
- HLSL

# Features

- Colouring
- Colour Conversion
- Colour  Blending
- Curves
- Blurring & Sharpening
- Serialisation
- Noise Generation
- Mask Generation

# Getting Started

To open the project Unity 2022.3.13 is required.
